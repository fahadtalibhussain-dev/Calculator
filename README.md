# Simple Calculator (Python Tkinter)

A simple graphical calculator built using Python and Tkinter.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal number support
- Clear button
- Error handling for invalid expressions

## Technologies Used

- Python 3
- Tkinter (Built-in GUI library)

## Project Structure

```
SimpleCalculator/
│── calculator.py
└── README.md
```

## Requirements

- Python 3.x

Tkinter comes pre-installed with Python, so no additional libraries are required.

## How to Run

1. Download or clone this project.

2. Open a terminal in the project folder.

3. Run:

```bash
python calculator.py
```

or

```bash
python3 calculator.py
```
